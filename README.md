# 🚆 Railway Train Finder

A Python-based railway utility for finding upcoming trains between **Jalna and Aurangabad (Chhatrapati Sambhajinagar)** using a selected travel time and day.

## ✨ Overview
The project combines a Flask API, an Oracle SQL database, and a Tkinter desktop interface to help users explore train options for a specific route.

## 🧰 Tech Stack
- Python
- Flask
- Oracle SQL
- Tkinter

## 🚀 Getting Started
1. Clone this repository.
2. Install the Python dependencies used by the project.
3. Configure your Oracle database connection and train data.
4. Run the Flask API and/or Tkinter interface according to the project entry points.

> **Note:** Database credentials and other secrets should be stored in environment variables or a local configuration file that is not committed to Git.

## 🎯 Purpose
A practical project exploring how software and database-backed applications can make everyday railway travel planning easier.
